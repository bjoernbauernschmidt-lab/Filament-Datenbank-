# Filament Manager

Lokale Web-App zur Verwaltung von 3D-Druck-Filament-Spulen.

## Enthaltene Materialien
PLA, PLA Matt, PLA Silk, PETG, PETG Matt, ABS, ASA, TPU, PA, Sonstiges

## Funktionen
- Spulen verwalten
- AMS-Slots und RFID-/Spulen-IDs
- Verbrauch buchen
- Restmengen korrigieren
- Verbrauchshistorie
- JSON-Backup exportieren/importieren
- Lokale Speicherung im Browser bzw. auf dem iPhone

## GitHub Pages
1. Lade `index.html` in ein öffentliches GitHub-Repository hoch.
2. Settings → Pages → Source: Deploy from a branch
3. Branch: main, Folder: / (root)
4. Save
5. Öffne https://BENUTZERNAME.github.io/filament-manager/ in Safari.
6. Teilen → Zum Home-Bildschirm → Hinzufügen.
